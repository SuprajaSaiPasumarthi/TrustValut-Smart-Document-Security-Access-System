# TrustVault – SecureDocs

## Project Description
TrustVault is a secure digital document vault that protects private documents through secure authentication, smart authorization, and transparent audit logging.

## Objectives
- Secure user registration and login.
- Allow users to upload and manage private documents.
- Prevent unauthorized document access.
- Provide controlled document sharing.
- Record important activities in an audit trail.

## Technology Stack
- Frontend: React
- Backend: Node.js and Express
- Database: PostgreSQL
- ORM: Prisma
- Authentication: JWT and bcrypt

## Security Features
- Password hashing.
- Authentication and authorization.
- Document ownership checks.
- Access control for shared documents.
- Audit logging.
